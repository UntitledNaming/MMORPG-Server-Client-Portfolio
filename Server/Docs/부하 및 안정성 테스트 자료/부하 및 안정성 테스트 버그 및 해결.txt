  몬스터가 섹터 업데이트 되거나, 캐릭터가 필드 진입하거나, 몬스터가 리젠될 때임.
- 솔직히 로직 상 버그인데 로직을 다시 봐도 일단은 모르겟음.
- 그러면 이를 찾기 위한 방법을 생각해보자. 즉, 서버에서 같은 몬스터 ID에 대해서 Create를 2번 보내거나 Delete를 2번 하거나
  하는 상황을 잡아보자. 이를 잡기 위해서 우선 유저 객체마다 전체 몬스터 ID를 index로 하고 bool 담는 배열을 하나 두고 해당 몬스터 ID에 대해서
  Create할때 bool을 true로 하고 Delete할때 false로 하려고 했는데 이건 좀 중단점은 잡는데 결국 이 유저에게 몬스터 생성, 삭제 패킷
  보내는 history 자체는 모름. 가장 최근의 한 행동만 아는 방식임.
- 그래서 배열이 int 타입 보다는 각 몬스터 ID에 대해서 Create, Delete history를 알 수 있게 원소가 int가 아니라 std::vector를 넣을 것임.
  이때 타입은 create, delete 타입과 이걸 한 위치를 표시하는 값 2개를 들 수 있게 구조체 형식으로 만들어서 넣을 것임.
